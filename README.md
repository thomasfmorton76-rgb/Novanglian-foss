# Curated FOSS Apps

A curated list of Free and Open Source Software.

## Legend
* 🌐 **No Network Permission** (Offline-capable)
* 📦 **Available on F-Droid**
* ⚠️ **Requires non-free server/service**

## Categories

### Productivity & Notes
* **[Markor](https://github.com)** 📦 - Lightweight Markdown editor for Android.
* **[Joplin](https://github.com)** - Note-taking and to-do application with sync capabilities.

### Security & Passwords
* **[KeePassDX](https://github.com)** 🌐 📦 - Multi-format password manager for Android.
* **[Aegis Authenticator](https://github.com)** 🌐 📦 - Free, secure, and open-source 2FA app.

### Media
* **[VLC](https://github.com)** 📦 - Cross-platform multimedia player.
* **[AntennaPod](https://github.com)** 📦 - Open-source podcast manager.
